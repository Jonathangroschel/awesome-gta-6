# GTA 6 Cheat Codes (PS5 & Xbox Series X\|S)

**Grand Theft Auto VI has 61 cheats.** They unlock only **after you finish the main story**, and each one also has its own challenge (shown under **Progress menu → Cheats**). As of November 20, 2026, the button inputs for **19** are public. The rest are still being found.

> **Status legend.** ✅ **Verified**: the same input appears in 2+ independent guides. ⚠️ **Single source**: only one guide lists it. ❓ **Not found yet**: the unlock requirement is known but the input isn't.

## How to enter cheats in GTA 6

1. Finish the main story and complete the cheat's unlock challenge.
2. Press **D-pad Up** to open the in-game phone.
3. **PS5:** hold **L1** and press **R1**. **Xbox:** hold **LB** and press **RB**.
4. Enter the D-pad sequence. A message confirms it worked.

**Before you use cheats:** they **disable trophies/achievements and saving** while active, so make a manual save first. Weather and screen filter cheats switch off when you enter the same code again. **There are no PC cheats** because there is no PC version yet.
